Validator Staking Masterclass: Panduan Partisipasi Jaringan Lumina L1

Panduan praktis langkah-demi-langkah bagi pemula untuk menjalankan node, mengekstrak identitas kriptografis (Node ID & BLS Public Key), dan menyetor stake secara dinamis menggunakan JavaScript SDK.

Halo calon Staker Premium Lumina! Menjadi validator di jaringan blockchain Layer 1 modern adalah cara terbaik untuk berpartisipasi menjaga keamanan desentralisasi sekaligus mendapatkan bagi hasil keuntungan (*passive income*) dari biaya transaksi (*gas fee*). Namun, bagi orang awam, istilah teknis seperti "Node", "BLS Public Key", "HotStuff BFT", dan "Staking" sering kali terdengar menakutkan.

Kabar gembira! Lumina didesain dari awal untuk mengedepankan **keamanan mutlak** berstandar industri dengan implementasi konsensus **HotStuff BFT (Byzantine Fault Tolerance)** berbasis tanda tangan **BLS12-381 teragregasi**. Dokumen ini ditulis khusus dengan bahasa yang ramah pemula untuk membimbingmu dari nol hingga server validator-mu memproduksi blok pertamanya di internet!

💡 Keamanan Dana Dijamin Aman: Di Lumina L1, koin taruhan (stake) milikmu **TIDAK PERNAH dikirim ke server validator** yang online. Koinmu tetap tersimpan aman di alamat dompet pribadimu secara offline di bawah perlindungan Mnemonic master-mu. Server validator hanya memegang kunci jaringan kosong untuk melakukan verifikasi suara konsensus!

🛡️ Keandalan Konsensus BFT Desentralisasi: Di Lumina v1.4, pengumpulan suara (*vote*) dilakukan secara terdesentralisasi via Gossip P2P oleh seluruh node online secara lokal (*Local QC Aggregation*). Hal ini menjamin Quorum Certificate (QC) selalu terbentuk dan blok tetap BFT-verified walaupun ada validator staker lain yang sedang offline!

1. Peta Jalan Partisipasi Validator (Konsep Dasar)

Untuk bergabung sebagai validator staker di jaringan Lumina, kamu akan melalui 3 langkah sederhana berikut:

1. Jalankan Server Node
➔
2. Ambil Node ID & BLS Pubkey
➔
3. Lakukan Transaksi STAKE (SDK/JS)

Langkah 1: Menjalankan Validator Node Pertama Kali

Server validator adalah sebuah komputer (bisa PC rumah atau sewa VPS Linux di cloud) yang menyala 24 jam sehari untuk mensinkronisasi data blok Lumina. Saat kamu menyalakan aplikasi node Lumina untuk pertama kalinya:

# Menjalankan node validator Lumina melalui terminal cargo run --release --bin lumina-node

Ketika perintah di atas dijalankan, node secara otomatis mendeteksi apakah kamu sudah memiliki file **`node.key`** (kunci rahasia identitas server). Jika belum punya, node akan **membuatkannya secara otomatis** di folder utama-mu! Berkas node.key inilah yang melambangkan "KTP elektronik" dari nodemu di internet.

Langkah 2: Mengambil ID Node & BLS Public Key (Identitas Kriptografis)

Setelah node menyala, lihat layar terminalmu atau gunakan perkakas CLI node untuk mengekstrak identitas kriptografis nodemu. Terdapat dua identitas penting yang wajib didaftarkan:

1. **Node ID (Peer ID)**: Alamat publik jaringan peer-to-peer (P2P) nodemu untuk pengiriman pesan gossip.
2. **BLS Public Key**: Kunci publik kriptografis BLS12-381 G1 (sepanjang 48-byte / 96 karakter heksadesimal) yang digunakan konsensus HotStuff BFT untuk memverifikasi keabsahan suara voting blok proposal secara matematis.

Tampilannya saat dicetak di log terminal akan terlihat mirip seperti ini:

INFO 🔑 Local Peer ID: 12D3KooWJnboL7zfBUNStAvppwax1HefV829Amptq78omiViHHjX INFO 🔑 BLS Public Key: ad59b0b8722ade3a926d26df1f7c66efead8cd6eb6a5367a4f287c3f35554c1152949b4df2966934bd91fccde0b66fd1 INFO 🚀 Node is syncing with Bootnode...

Salin (*copy*) kedua teks tersebut ke dalam notepad-mu! Keduanya adalah identitas publik nodemu yang akan kita daftarkan di transaksi staking agar suaramu sah secara matematis di dalam agregator konsensus BFT.

📂 Lokasi Kunci Rahasia: Di folder utama nodemu, file bernama node.key sekarang telah tercipta. File ini berisi *Private Key* dari server nodemu. Cadangkan file ini di tempat yang aman! Siapa pun yang memiliki file ini bisa menjalankan node atas namamu, namun mereka **TIDAK BISA mengambil koinmu**.

Langkah 3: Melakukan Staking Menggunakan SDK Javascript

Untuk mengajukan nodemu ke jaringan validator resmi, kamu harus mengunci minimal **10.000 LUM** sebagai modal komitmen staker. Kita bisa melakukannya secara instan menggunakan script JavaScript sederhana bernama **`test_stake.js`** yang memanfaatkan SDK resmi Lumina!

Di bawah ini adalah isi dari berkas test_stake.js yang sudah disiapkan di dalam folder proyekmu:

import { LuminaWallet, LuminaClient } from './lumina-blockchain-sdk/js/src/index.js'; // 1. Hubungkan ke server RPC resmi Lumina const client = new LuminaClient('https://rpc1.bariscode.my.id'); // 2. Masukkan Private Key Dompet Pribadimu (Jangan taruh di server validator!) const nodeWallet = new LuminaWallet("c37429dc912e4913b6..."); async function runTest() { // Salin Node ID dan BLS Public Key yang kamu dapatkan di Langkah 2 ke sini! const NODE_ID = "12D3KooWJnboL7zfBUNStAvppwax1HefV829Amptq78omiViHHjX"; const BLS_PUBKEY = "ad59b0b8722ade3a926d26df1f7c66efead8cd6eb6a5367a4f287c3f35554c1152949b4df2966934bd91fccde0b66fd1"; console.log("🦾 Memulai penguncian dana (Staking)..."); try { // 3. Buat transaksi stake sebesar 10.000 LUM terikat ke Node ID & BLS Public Key-mu const stakeTx = await nodeWallet.createStakeTransaction(client, { amount: "10000000000000000000000", // Satuan Lumlets (10,000 LUM) nodeId: NODE_ID, blsPubKey: BLS_PUBKEY }); // 4. Kirim transaksi ke jaringan const stakeRes = await client.sendTransaction(stakeTx); console.log("✅ TRANSAKSI STAKING BERHASIL DIKIRIM!"); console.log("📜 TX Hash:", stakeRes.hash); } catch (e) { console.error("🛑 GAGAL STAKING:", e.message); } } runTest();

Untuk menjalankan script di atas di laptopmu, pastikan Node.js telah ter-install, lalu jalankan perintah berikut di terminal:

node test_stake.js

Langkah 4: Verifikasi Sukses (Selamat Bergabung!)

Setelah script staking berjalan sukses, lihat kembali layar log terminal dari Server Validator Rust-mu. Dalam hitungan detik, node validator-mu akan menangkap transaksi staking-mu dari blockchain dan memunculkan notifikasi kemenangan ini:

INFO 🦾 Validator Registered! Addr: lumina1xxxx...xxxx, NodeId: 12D3KooW... INFO ✨ Node is now an Active Validator in HotStuff Consensus!

Selamat! Server validator-mu sekarang secara resmi telah terdaftar di database blockchain Lumina. Setiap kali jaringan Lumina memproses transaksi, validator-mu akan ikut memverifikasi blok dan saldo biayanya akan masuk ke dompet pribadimu secara otomatis!

Keuntungan & Hak Istimewa Staker

💰 Pembagian Gas Fee Jaringan

Setiap blok yang diusulkan oleh validator staker akan mendapatkan alokasi bagi hasil sebesar **90% dari total biaya transaksi (Gas Fee)** di dalam blok tersebut.

🏆 Staking Reward Elite

Secara berkala, top 30 staker dengan jumlah koin terkunci terbanyak akan masuk ke dalam jajaran validator elit dan berhak mendapatkan bonus inflasi minting tambahan.

⚠️ Aturan Penting Validator:

Pastikan server validator-mu memiliki koneksi internet yang stabil dan menyala 24/7. Jika server validator-mu sering mati (*downtime* tinggi) atau melakukan kecurangan data, sistem konsensus dapat memotong skor reputasi validator-mu demi menjaga kesehatan jaringan.
