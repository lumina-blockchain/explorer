Node Architecture: Modular Crate Layout

Membedah struktur kernel Rust Lumina yang super-modular guna menjamin skalabilitas tinggi dan kompilasi biner yang ramping.

Seiring berkembangnya kompleksitas sistem blockchain, arsitektur monolitik yang menggabungkan seluruh logika dalam satu folder besar akan menjadi bumerang. Kode menjadi sulit dipelihara, unit testing berjalan sangat lambat, dan penggantian satu database memerlukan perombakan jutaan baris kode.

Lumina dibangun dengan **Arsitektur Modular** berbasis multi-crate di dalam workspace Cargo Rust (Cargo.toml). Hal ini memberikan batas isolasi yang tegas (*separation of concerns*), mempermudah pengujian terpisah, serta memungkinkan penggantian satu modul tanpa memengaruhi modul lainnya.

2. Penjelasan Detail Fungsi Crate

📦 lumina-primitives
Fondasi tipe data global. Berisi definisi objek utama blockchain seperti Address (Bech32m), Hash (Blake3), Transaction, dan Block. Semua crate lain bergantung pada primitives ini.
📦 lumina-crypto
Modul kriptografi inti. Menyediakan BLS12-381 signature aggregation, pairing-friendly cryptography, SLIP-0010 HD wallet derivation, dan Blake3 hash utility.
📦 lumina-storage
Manajer database permanen. Mengimplementasikan antarmuka data persistence menggunakan **RocksDB** untuk menyimpan riwayat block, state accounts, dan metadata dengan throughput I/O sangat tinggi.
📦 lumina-network
Modul P2P Networking. Dibangun di atas libp2p dengan protokol Gossipsub untuk penyiaran block & transaksi cepat, serta Kademlia DHT untuk pencarian peer otonom di internet.
📦 lumina-executor
Mesin virtual WebAssembly. Menggunakan runtime Wasmtime untuk mengeksekusi bytecode smart contract Rust dengan performa hardware-native.
📦 lumina-state
The State Engine. Mengatur saldo, mengeksekusi state transition, mendistribusikan reward staking pool, dan melakukan validasi transaksi sebelum ditandatangani oleh validator.
📦 lumina-consensus
Mekanisme Konsensus. Menyediakan antrean Mempool (dengan prioritasi gas fee) serta HotStuff-BFT consensus engine yang melakukan rotasi Leader otonom setiap 15 detik.
📦 lumina-api
Lapisan Server HTTP RPC & WebSocket. Dibangun di atas framework **Axum** untuk melayani query data Explorer, submit transaksi dApps, dan broadcast event WebSocket real-time.
📦 lumina-node
Biner eksekusi utama (Main Entry Point). Merakit semua crate di atas menjadi satu kesatuan executable binary yang dapat dijalankan melalui baris perintah CLI.

3. Optimasi Kompilasi Rilis Terpadu

Untuk memastikan performa bare-metal terbaik sekaligus mengecilkan ukuran biner WASM dan biner node, Lumina menyuntikkan optimasi profil kompilator tingkat lanjut di Cargo.toml:

⚙️ Flag Profil Rilis Workspace

[profile.release] opt-level = 'z' # Fokus mengecilkan ukuran binari (z = size) lto = true # Aktifkan Link-Time Optimization global codegen-units = 1 # Bikin kompilasi lebih lambat tapi hasil biner optimal panic = 'abort' # Buang mesin penanganan error stack yang berat strip = true # Hapus simbol debug yang tidak diperlukan dari biner
