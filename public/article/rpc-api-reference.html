RPC API Reference

Spesifikasi teknis super-detail dari antarmuka HTTP JSON-RPC 2.0 dan REST API di dalam kernel node Lumina.

Node Lumina secara default meluncurkan server RPC berkinerja tinggi yang ditenagai oleh framework Axum pada port dinamis yang dihitung dari konfigurasi P2P port:

RPC Port = 9090 + (p2p_port % 10) // Port Default = 9098 (P2P = 61688)

⚠️ Konversi Satuan & Presisi Aman (Floating Point Loss Prevention)

Lumina menggunakan presisi **18 digit desimal** (seperti Ethereum). Satuan terkecil disebut **Lumlets**. Karena keterbatasan parser integer JavaScript dalam menangani nilai $u128$ raksasa, RPC Lumina **wajib** menerima angka besar dalam format **String-based JSON** (misal: "valueString" dan "feeString").

  • • 1 LUM = 1.000.000.000.000.000.000 Lumlets (u128)
  • • Minimal Priority Gas Fee = 10.000.000.000.000 Lumlets

🌐 Protokol JSON-RPC 2.0 (Spesifikasi Penuh)

Node Lumina mengekspos rute tunggal POST /rpc yang sepenuhnya kompatibel dengan standar protokol JSON-RPC 2.0. Endpoint ini mendukung fitur mutakhir seperti Batch Requests (mengeksekusi banyak panggilan metode dalam satu array JSON) untuk efisiensi latensi maksimal.

Branded JSON-RPC 2.0 Interface

Untuk konsistensi merek dan standarisasi API Lumina L1, seluruh metode JSON-RPC diekspos di bawah penamaan namespace resmi lum_*:

Metode Lumina Resmi Deskripsi Fungsi
lum_getLatestBlockHeight Mengambil tinggi blok tertinggi saat ini di blockchain Lumina.
lum_getBalance Membaca saldo koin, jumlah stake, dan nonce dari alamat dompet Lumina.
lum_getBlockByNumber Mengambil data blok detail berdasarkan tinggi nomor blok.
lum_sendRawTransaction Mengirim transaksi yang telah ditandatangani ke Mempool node.
lum_getFee Mengambil estimasi priority gas fee dinamis saat ini.
lum_getContractBytecode Mengambil bytecode smart contract WASM yang dideploy.
lum_getContractStorage Membaca storage internal state variables dari kontrak WASM.
lum_getRecentBlocks Mengambil metadata 20 blok teranyar secara efisien.
lum_getNetworkStats Membaca statistik validator aktif, peer terhubung, ID rantai, dan TPS saat ini.
lum_getRecentTransactions Mengambil daftar 10 transaksi teranyar yang masuk ke blok.
lum_getTransactionByHash Mengambil data transaksi individual berdasarkan hash 32-byte.
lum_globalSearch Mencari entitas instan secara cerdas (address, height, block/tx hash).
lum_getRecentMempool Mengambil hingga 50 antrean transaksi pending mempool.
lum_getMempoolByAddress Filter transaksi pending mempool berdasarkan alamat pengirim/penerima.

lum_getBlockEvents Membaca seluruh log event yang dipancarkan smart contract di blok.

📚 Dokumentasi Detail 16 Metode Resmi JSON-RPC 2.0

Di bawah ini adalah spesifikasi request payload dan response lengkap untuk setiap metode resmi yang aktif di Node Lumina:

JSON-RPC lum_getLatestBlockHeight

Mengambil indeks/tinggi nomor blok tertinggi saat ini yang berhasil divalidasi oleh konsensus BFT.

Request Payload:
{ "jsonrpc": "2.0", "method": "lum_getLatestBlockHeight", "params": [], "id": 1 }
Response JSON:
{ "jsonrpc": "2.0", "result": 14205, "id": 1 }
JSON-RPC lum_getBalance

Membaca status real-time saldo akun (LUM), status stake, dan nonce pengirim berikutnya dari database state.

⚡ REST API Endpoints (Backward Compatibility)

Selain antarmuka JSON-RPC 2.0 tunggal, Lumina Node juga menyediakan rute REST API klasik berbasis rute GET untuk kompatibilitas instan:

POST /submit

Mengirim transaksi baru yang ditandatangani ke mempool jaringan untuk divalidasi dan diusulkan.

Response JSON:
{ "status": "success", "hash": "0x56a1b2d..." }
GET /balance/:address

Membaca saldo, koin yang di-stake, dan nonce terbaru dari akun secara real-time dari global state.

Response JSON:
{ "address": "lumina1c3f2d...", "balance": "99955000000000000000", "staked": "500000000000000000", "nonce": 12 }
WS /explorer/ws

WebSocket Live Broadcaster. dApps atau block explorer dapat melakukan koneksi untuk menerima notifikasi real-time setiap kali transaksi baru dikirimkan, block baru diproduksi, atau staker baru ditambahkan.

Event Message Payload:
{ "type": "NEW_BLOCK", "data": { "height": 300, "hash": "0x89e21d...", "proposer": "lumina1...", "tx_count": 14, "timestamp": 1779836372 } }
