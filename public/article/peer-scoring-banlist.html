Peer Scoring & Banlist Engine

Sistem Pertahanan Otonom & Reputasi Node untuk Melindungi Kedaulatan Jaringan P2P Lumina

Di dalam jaringan blockchain tanpa izin (permissionless), staker dan validator terus-menerus bertukar informasi melalui protokol P2P Gossipsub dan RequestResponse Sync. Namun, tidak semua node beroperasi dengan itikad baik. Serangan spamming transaksi sampah, blok palsu, hingga pengiriman data sinkronisasi yang rusak (corrupted data) berpotensi merusak kestabilan jaringan.

Untuk mengatasi hal tersebut, Lumina menerapkan Peer Scoring & Banlist Engine. Sistem ini memantau perilaku setiap Peer secara in-memory secara real-time, memberikan penilaian reputasi yang ketat, dan secara otomatis memutus serta memblokir (banning) node penyerang dari jaringan secara instan.

Filosofi Keamanan: Lebih baik mendepak satu node nakal lebih cepat daripada menanggung resiko delay propagasi konsensus di seluruh jaringan staker!

1. Struktur Data Reputasi (In-Memory)

Sistem penilaian melacak setiap node terhubung secara efisien di dalam memori menggunakan struktur data thread-safe PeerScoringManager yang dapat diakses simultan oleh event loop P2P Swarm dan Axum RPC Server.

pub struct PeerScore { pub score: i32, // Dimulai dari 100, min 0, max 100 pub bad_actions_count: usize, // Frekuensi kesalahan yang dilakukan pub last_penalty_reason: Option<String>, // Catatan pelanggaran terakhir }

2. Matriks Pelanggaran & Poin Penalti

Setiap kali node lain mengirimkan paket data ke node kita, datanya akan divalidasi terlebih dahulu. Jika validasi gagal, pelaku (source peer) akan menerima pengurangan poin secara instan sesuai tingkat keparahan pelanggarannya:

Gossip Tx Signature Error

-20 Poin

Diberikan saat node mempropagasikan transaksi dengan tanda tangan kriptografi (signature) yang tidak valid atau palsu.

Sync Corrupted Blocks

-30 Poin

Diberikan saat peer merespon permintaan sinkronisasi (SyncRequest) dengan deretan bytes blok yang rusak atau gagal didekode.

Gossip Block Apply Failure

-40 Poin

Penalti terberat! Diberikan ketika staker mempropagasikan proposal blok baru lewat Gossipsub yang ilegal atau melanggar aturan konsensus state.

Good Behavior Recovery

+5 Poin (Recovery)

Node yang berkelakuan baik dan terus berkontribusi memverifikasi data secara jujur secara bertahap akan dipulihkan skornya hingga kembali ke 100.

3. Mekanisme Pemutusan & Banning Instan

Begitu skor reputasi peer menyentuh angka 0 atau negatif, mesin penalti P2P Lumina akan memicu aksi pertahanan tingkat tinggi secara otomatis:

if new_score <= 0 { tracing::error!("🚫 PeerId {} is banned! Disconnecting...", peer_id); let _ = self.swarm.disconnect_peer_id(peer_id); }

Sistem Proteksi Gerbang Masuk (Shield Mode)

Tidak hanya memutus koneksi aktif, peer yang telah masuk ke daftar cekal (banlist) skor 0 akan langsung didepak saat pertama kali mencoba membangun jabat tangan (handshake) koneksi di event ConnectionEstablished. Hal ini menghemat resource CPU dan bandwidth node kita secara signifikan!

4. REST RPC API Endpoint (/network/peers)

Developer, staker, dan validator dapat memantau kesehatan jaringan serta daftar blacklist peer secara langsung melalui endpoint Axum HTTP RPC:

// GET http://127.0.0.1:9098/network/peers { "peers": [ { "peer_id": "12D3KooWSC9k5sK1oXzDUjmm4q3rXk4Qok3D9nHsfM3actXRvj3N", "score": 80, "bad_actions": 1, "last_penalty_reason": "Invalid transaction signature" } ] }

Mekanisme in-memory ini terintegrasi sempurna dengan launcher multi-node Lumina, memastikan performa maksimal dengan latensi mikrodetik pada sistem multi-thread rust tokio runtime.
