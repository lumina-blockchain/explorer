SDK & Client Library | Mei 2026

Lumina Rust SDK client-v0.1.0

Panduan integrasi Rust SDK (lumina-std) untuk manajemen kunci (Keypair), penyusunan transaksi lokal, dan interaksi JSON-RPC asinkronus ke Lumina L1 Node.

Untuk mempercepat pengembangan integrasi backend, validator tools, bursa (exchanges), maupun scheduler otomatis, blockchain Lumina L1 menyediakan Rust SDK resmi berkinerja tinggi. Crate lumina-std dikompilasi ganda (dual target): mendukung eksekusi bare-metal tanpa pustaka standar #![no_std] untuk target smart contract WASM, serta mode standard library penuh client untuk native platform.

# Tambahkan dependensi ke Cargo.toml proyek Rust Anda [dependencies] lumina-std = { path = "path/to/sdk", features = ["client"] }

1. Fitur Utama Rust SDK

Target fitur client menyediakan tiga pilar utama bagi pengembang:

  • Modul Wallet: Manajemen kunci berbasis Ed25519. Mendukung entropy generator OS (acak), pemulihan kata sandi mnemonic 12/24 kata (BIP-39 & SLIP-0010), pemulihan kunci privat mentah (raw secret bytes), serta penandatanganan transaksi secara offline.
  • Modul Transaction: Pembangun transaksi berbasis fluent builder pattern (TxBuilder) untuk penyusunan data biner transfer, data payload smart contract, nonce, dan tanda tangan sponsor biaya (Sponsored Transaction).
  • Modul Client: Wrapper asinkronus HTTP JSON-RPC 2.0 (LuminaClient) untuk query saldo akun, tinggi blok terbaru, pelacakan detail blok, pengecekan nonce aktif, dan penyerahan transaksi ke mempool.

2. Arsitektur Integrasi Server-Client

SDK Rust mengisolasi seluruh operasi penandatanganan kriptografis di sisi client secara lokal (Zero-Knowledge Private Key Leakage). Node hanya menerima objek tanda tangan (SignedTransaction) yang valid secara matematis:

💡 Presisi Nilai: Untuk menghindari ketidakakuratan atau floating-point precision loss pada bahasa pemrograman dinamis (misalnya Javascript), API Node menerima saldo dan biaya gas dalam representasi String khusus (valueString dan feeString) yang otomatis dipetakan secara mulus oleh LuminaClient.

3. Contoh Implementasi Lengkap (Demo Test)

Berikut adalah kode utuh yang melakukan sinkronisasi dengan blockchain node lokal, memulihkan dompet, dan mengirimkan transaksi transfer koin:

use lumina_std::client::LuminaClient; use lumina_std::wallet::Wallet; use lumina_std::transaction::TxBuilder; use lumina_primitives::Address; #[tokio::main] async fn main() -> Result<(), Box<dyn std::error::Error>> { // 1. Hubungkan ke HTTP JSON-RPC Port di Node (default: 9098) let rpc_url = "http://127.0.0.1:9098"; let client = LuminaClient::new(rpc_url, None)?; // 2. Ambil tinggi blok saat ini let height = client.get_latest_block_height().await?; println!("📦 Tinggi Blok: #{}", height); // 3. Pulihkan Wallet Genesis Sultan menggunakan Private Key Hex let secret_hex = "fdc94d54460e2b7e548f294bb58e4d525b5a67cd95ed7de2be477a9379db2630"; let secret_bytes = hex::decode(secret_hex)?; let wallet = Wallet::from_secret_bytes(&secret_bytes)?; println!("🔑 Alamat Wallet: {}", wallet.address()); // 4. Periksa saldo on-chain dalam satuan Lumlets (BigInt desimal 18) let balance = client.get_balance(&wallet.address()).await?; println!("💰 Saldo Wallet: {} Lumlets", balance); // 5. Dapatkan Nonce akun terbaru dari mempool state let nonce = client.get_nonce(&wallet.address()).await?; println!("🔢 Nonce Aktif: {}", nonce); // 6. Bangun transaksi transfer 500 Lumlets ke alamat tujuan let receiver = Address::from_bytes([9u8; 20]); let tx = TxBuilder::new(wallet.address(), receiver, 500) .nonce(nonce) .fee(20_000_000_000_000) // Biaya gas minimum .build(); // 7. Tandatangani transaksi secara lokal di sisi client let signed_tx = wallet.sign_transaction(tx); println!("✍️ Transaksi berhasil ditandatangani lokal. Hash: {}", signed_tx.transaction.hash()); // 8. Siarkan (Broadcast) ke node let tx_hash = client.send_transaction(signed_tx).await?; println!("📡 Sukses diserahkan! Hash Respon: {}", tx_hash); Ok(()) }

4. Hasil Eksekusi & Validasi Keamanan Mempool

Saat transaksi diserahkan ke mempool node, ada dua skenario penting yang divalidasi oleh RPC server:

Skenario A: Sukses Masuk Mempool

Jika nonce sesuai dan saldo pengirim mencukupi untuk menutupi biaya transfer + gas fee, transaksi akan diterima oleh mempool untuk ditambang:

Tx Hash: 0xb742d7ac67eb3d0528d34527abcd95aa2e06c9dc22a74f2d7455aff5796c18a6

Skenario B: Proteksi Nonce Duplikat

Jika Anda mencoba mengeksekusi kembali transaksi dengan nonce yang sama saat transaksi pertama masih mengantre di mempool, server node secara otomatis akan melarangnya dengan respon error:

📡 Mengirim transaksi ke mempool node... ❌ Transaksi gagal dikirim: JsonRpcError { code: -32602, message: "Nonce already in mempool" }

Hal ini mencegah serangan replay-attack atau pembelanjaan ganda (double-spend) sebelum block di-mint (ditambang) oleh sistem konsensus leader.

5. Spesifikasi API Metrik

Metode & Parameter Penjelasan Fungsi & Respon
LuminaClient::new(url, api_key) Membuat instance client baru. Mendukung token autentikasi X-API-Key jika dikonfigurasi.
client.get_balance(&addr) Mendapatkan saldo aktif akun pengirim (u128) dari on-chain state trie database.
client.get_nonce(&addr) Mendapatkan nilai counter nonce (u64) terbaru milik pengirim.
client.send_transaction(signed_tx) Mengirimkan transaksi biner yang ditandatangani ke node. Mengembalikan hash transaksi (String).
