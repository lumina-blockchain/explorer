SDK Integration & Client Library | May 2026

Lumina JS SDK NPM v1.2.0

Toolkit integrasi JavaScript/TypeScript terlengkap untuk memanggil RPC node, menyusun transaksi binary Bincode, dan berinteraksi dengan smart contract WASM.

Untuk mempermudah interaksi aplikasi frontend, dompet dApps, maupun backend bot staking dengan blockchain Lumina, kami menyediakan SDK resmi yang ringan dan andal. SDK ini menangani serialisasi biner varint Rust, tanda tangan Ed25519 tweetnacl, penanganan string presisi, dan koneksi WebSocket otonom.

npm install lumina-blockchain-sdk

1. Manajemen Dompet & HD Wallet Derivasi

Lumina menggunakan standard **Coin Type 616** untuk identitas dompet jaringannya. SDK mendukung pembentukan dompet dari seed phrase bip39 dengan index derivasi bip44 secara aman:

import { LuminaWallet } from 'lumina-blockchain-sdk'; // 1. Buat Dompet Acak Baru const wallet = LuminaWallet.createRandom(); console.log("Address:", wallet.getAddress()); console.log("Public Key Array:", wallet.getPublicKey()); // 2. Pulihkan Dompet dari Mnemonic & HD Derivasi (Coin Type 616) // Path standard: m/44'/616'/0'/0/index const mnemonic = "alpha bravo charlie ... word12"; const hdWallet = LuminaWallet.fromMnemonic(mnemonic, 0); // Index = 0 console.log("HD Address:", hdWallet.getAddress());

2. Presisi Aritmatika Tinggi (High-Precision Units)

💡 floating-point anti-loss: Lumina melarang pembulatan angka pecahan mengambang. Gunakan utility LuminaUtils untuk konversi angka String LUM ke satuan Lumlets (BigInt desimal 18):

import { LuminaUtils } from 'lumina-blockchain-sdk'; // Konversi 10.5 LUM ke Lumlets (BigInt) const Lumlets = LuminaUtils.toUnits("10.5"); console.log(Lumlets); // 10500000000000000000n (BigInt) // Konversi Lumlets ke String desimal LUM const LUM = LuminaUtils.toLumina(Lumlets); console.log(LUM); // "10.5" (String)

3. Fitur Unggulan: Sponsored Transaction

Lumina menyokong transaksi gasless (bebas gas) bagi pengguna akhir melalui skema **Fee Payer (Sponsor)**. Transaksi dikirim oleh pengguna, gas-nya dibayar oleh akun sponsor sekunder:

// 1. User menandatangani transaksi dengan mendaftarkan alamat Sponsor const userTx = userWallet.signTransaction( receiverAddress, // Alamat penerima "1000000000000000000", // 1 LUM dalam Lumlets nonce, // Nonce pengguna [], // Data/payload kosong sponsorAddress, // Alamat pembayar gas "10000000000000" // Gas Fee ); // 2. Sponsor menandatangani payload userTx sebagai pembayar gas const fullySignedTx = sponsorWallet.signAsFeePayer(userTx); // 3. Broadcast ke RPC await client.sendTransaction(fullySignedTx);

4. Manajemen RPC & WebSocket Live Connection

Gunakan kelas LuminaClient untuk berinteraksi dengan API node, melacak estimasi gas fee berdasarkan byte transaksi, serta mengaktifkan pemantauan real-time via WebSocket:

import { LuminaClient } from 'lumina-blockchain-sdk'; const client = new LuminaClient("http://127.0.0.1:9095"); // A. Ambil Saldo const state = await client.getBalance(wallet.getAddress()); console.log("Nonce:", state.nonce); // B. Estimasi Gas Fee dinamis berdasarkan ukuran payload const fee = await client.estimateFee([1, 2, 3, 4]); console.log("Estimated Fee (Lumlets):", fee); // C. Tunggu konfirmasi transaksi secara instan lewat WebSocket /explorer/ws try { await client.waitForConfirmationWS(txHash); console.log("Transaction Confirmed! 🎉"); } catch (err) { console.error(err); }

Spesifikasi Kelas & Metode Utama

Kelas & Metode Penjelasan Fungsi & Keterangan
LuminaUtils.isValidAddress(addr) Memeriksa validitas format Bech32m prefix lumina.
LuminaWallet.createRandom() Membuat dompet acak baru menggunakan dalek-ed25519 secure entropy.
wallet.createStakeTransaction(...) Menyusun transaksi staking biner dengan format prefix STAKE dan data Peer ID.
client.getTransaction(hash) Melacak data detail transaksi terproses.
