Hybrid Elite Staker Model & Reward Distribution

Evolusi alokasi reward di jaringan Lumina untuk menyelaraskan keadilan validator kecil dengan komitmen staker kelas kakap.

Di dalam sistem blockchain Proof-of-Stake (PoS) tradisional, seluruh bagi-hasil keuntungan sering kali disapu bersih oleh staker raksasa yang memiliki modal tak terbatas. Validator dengan infrastruktur prima namun memiliki koin kecil sering kali terpinggirkan dan enggan berpartisipasi menjaga stabilitas jaringan.

Lumina memecahkan ketimpangan ini dengan menerapkan **Hybrid Elite Staker Model**. Model ini memisahkan insentif kerja keras validator (proposer blok) dengan keuntungan keamanan modal staker. Dengan model ini, kami menjamin **keadilan bagi pekerja (validator kecil)** dan tetap memberikan **insentif elite bagi staker utama (Top 30)**.

1. Pembagian Alokasi Reward 90/10

Dalam setiap pembuatan satu blok Lumina yang sukses, terdapat pembagian ekonomi yang sangat presisi:

100% + 10%

Proposer / Leader Reward

Siapapun yang terpilih sebagai Leader dan sukses memproduksi blok akan menerima **100% Block Emission Reward** ditambah **10% dari total Gas Fees** di blok tersebut sebagai biaya upah operasional.

90% Pool

Elite Fee Pool (Top 30)

Sisa **90% dari total Gas Fees** dikumpulkan secara terpusat dan dibagikan secara proporsional **hanya kepada 30 Validator Teratas** (Top 30 Elite Stakers) dengan jumlah koin terkunci terbanyak.

2. Formula Distribusi & Proteksi Overflow

Biaya gas dari transaksi didistribusikan kepada masing-masing anggota dari Elite Group secara proporsional. Namun, dalam aritmatika integer di komputer, perkalian angka besar (u128) dapat memicu **Overflow Crash (System Panic)**.

Untuk mengatasinya, State Manager Lumina dilengkapi **Overflow Protection Scaling** di mana nilai stake akan dipangkas pembagi $10^9$ saat total elite stake melewati batas aman:

V_share = V_stake * SharedPool / EliteTotalStake

3. Kode Rust: Distribusi Hadiah Blok

Di bawah ini adalah kode sumber riil dari engine distribusi state Lumina di dalam crates/state/src/lib.rs yang menghitung bagi hasil staker elit:

// 1. Berikan Upah Dasar + 10% Biaya Gas kepada Leader Proposer let mut leader_state = self.get_account(&leader); leader_state.balance += total_leader_reward; self.update_account(leader.clone(), leader_state); // 2. Ambil Sisa Pool Biaya Gas (90%) untuk Didistribusikan let shared_pool = total_gas_fees - leader_fee_bonus; // 3. Ambil Semua Validator Aktif yang Memiliki Stake let mut all_validators = self.get_active_validators_with_stake(); // 4. Urutkan Berdasarkan Stake Tertinggi & Ambil Top 30 (Elite Group) all_validators.sort_by(|a, b| b.stake.cmp(&a.stake)); if all_validators.len() > MAX_ELITE_VALIDATORS { all_validators.truncate(MAX_ELITE_VALIDATORS); } let elite_total_stake: u128 = all_validators.iter().map(|v| v.stake).sum(); if elite_total_stake > 0 { for v in all_validators { // --- SCALE DOWN JIKA OVERFLOW SAFEGUARD TERPAKU --- let v_share = if elite_total_stake > 1_000_000_000_000_000_000 { let scaled_stake = v.stake / 1_000_000_000; let scaled_total = elite_total_stake / 1_000_000_000; scaled_stake * shared_pool / scaled_total } else { v.stake * shared_pool / elite_total_stake }; let mut v_state = self.get_account(&v.address); v_state.balance += v_share; self.update_account(v.address, v_state); } }

4. Dampak Ekonomi Bagi Ekosistem

  • Gaji Adil Untuk Proposer Kecil: Validator kecil dengan stake minimum tetap mendapatkan imbalan 100% Block Reward saat giliran mereka mengusulkan blok, menjamin kelayakan biaya listrik & infrastruktur server.
  • Penjaga Keamanan Kuat (Elite Group): Top 30 staker didorong secara ekonomi untuk terus meningkatkan staking modal mereka demi mendapatkan bagi hasil 90% gas fee yang berlipat ganda saat jaringan ramai transaksi.
